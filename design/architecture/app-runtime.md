# 应用运行平台：保活、导航与系统服务

> 状态：已定稿（2026-10-31）｜对应实现：web/src/runtime/｜接口见 docs/APP-RUNTIME.md

用户目标：插件应用像手机应用一样，切走只进入后台，切回继续使用。

## 决策

1. 安装事实归服务端 ledger；前端打开实例归 appRuntime，二者不能混为同一生命周期。
2. 使用稳定窗口容器保留组件和 iframe，不对 iframe 使用会分离 DOM 的通用 KeepAlive 包裹。
3. 元数据发现与插件 setup 分离，首次使用才初始化；预取和预执行分别配置。
4. 当前一应用一实例，先完成多应用驻留、桌面分屏和无环嵌套；不引入自由拖动窗口管理。
5. 原生插件通过 scoped UiCtx、page 通过同源 MessageChannel SDK 使用同一类系统服务。
6. 保留现有宿主返回边界；iframe 逻辑栈通过 SDK 合作式接入，避免与浏览器物理历史抢控制。
7. 不增加 Wujie/MicroApp 依赖，不将框架名写入插件契约，未来可增加适配器。
8. 常驻界面上限 10，按最近使用顺序回收可关闭后台窗口；当前/分屏、继续运行和关闭保护跳过，全受保护则拒绝第 11 个实例。
9. Dock 状态通过长线/小点呈现；图标右键/长按菜单提供应用操作，取消额外数量入口。

## 未宣称的能力

同源插件恶意代码隔离、浏览器永久后台运行、任意第三方 SPA 的无改造路由接管、
自动保存所有插件内存、原生 ESM 模块驱逐与 AI 新功能均不在本次实现的承诺内。
