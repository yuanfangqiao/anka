# 中心移动与顶排转身：当前手感规则

> 2026-10-30｜用户提出并授权实施。替代07的长按转向建议。
> ESP 0.4.1 / 游戏1.4.1；半格起转取代0.4.0的一格门槛。手机保持用户选择的LAN HTTP。
> 功能对照、公式及实现位置见[两端对齐与实时转身](10-controller-parity-and-live-turn.md)。

## 操作

| 起手与操作 | 结果 |
|---|---|
| 中央圆短点 | 跳跃 |
| 中央圆按下后拖动 | 连续二维移动，支持斜向 |
| 顶排短点 | 原换弹/切武器/手雷功能 |
| 顶排首次水平位移不超过半格 | 不转身；已经成为拖动的手势不触发功能 |
| 顶排向右横滑超过半格 | 顺时针/向右激活，门槛后每格180°、1/3格60° |
| 顶排向左横滑超过半格 | 逆时针/向左激活，门槛后按相同位移比例转身 |
| 激活后同次按住反向回滑 | 立即跟随反向，不重复死区，不限定一次只能转180° |
| 其他格短点 | 原功能 |
| 其他格拖动 | 消费此次触摸，不移动、不转身、不触发功能 |

按下时锁定起点用途，到抬手结束。中心拖进顶排仍移动，顶排进入其他格也不会切换为移动。首版触控区只跟踪首个手指，双主键保持独立并发，不新增双指移动/转向组合。

## 跟手门槛

手机使用相邻功能格的实际列间距作为一格；ESP使用152个逻辑像素。首次水平位移严格超过半格才激活，门槛后每格180°。

激活时锁定正或负半格锚点；之后角度=(当前水平位移−锚点)×180°/格距。锚点到抬手都不变，因此回到最初死区内也能连续反向。停住手指不继续转，抬手保留当时方向。零变化不产生新转身更新，不使用10°硬量化造成阶梯。

顶排纵向偏移超过半格时取消本次转向资格，避免向下拖动被识别为转身。若已经产生部分转角则保留该转角，不补发功能。

## 视觉

中心移动继续显示青色轨迹。顶排拖动显示半格门槛线和进度，跨过后变成金色，箭头跟随实际转动方向。跳跃圆环绿/红继续表示在线/离线。

## 传输与镜头

input保留可选turn：归一化到[-180,180]的累计转角，右正。0.4.1增加turnTotal，保存未取模的完整累计角度，游戏1.4.1优先用其差值，避免快滑跨180°被误判反向。两者都是持久快照，不是持续角速度或每包累加的delta。

设备/手机在抬手、普通输入释放和重连时保留turn；重连neutral帧包含当前turn。服务端合并连续输入时保留最新快照，避免快速滑动的最后一个角度被抬手帧覆盖。neutral只检查保持输入，不因非零turn而阻塞。

游戏应用最新turnTotal相对已应用总角度的差值；旧客户端仍用turn圆周差值。差值加入持久镜头基准，体感回正不撤销屏幕转身，重复快照不产生额外旋转。暂停/失焦/超时恢复时以首个neutral快照重建基线，不回放期间输入。角色继续沿当前准星方向转身，不扩展头部/躯干独立动画。
