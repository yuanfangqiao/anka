# Web Use：让 Agent 操作当前 Anka 窗口

在对话页点击「网页操作」，等状态变为「网页操作已开」，再发送例如「打开笔记应用，在搜索框填入海边」。
默认对话仍走插件开发工具；网页操作模式使用本页可控的插件及专用工具。使用支持工具调用的模型；
需要看图时，选择同一端点同时支持图像输入和工具调用的模型。

| 工具 | 作用 |
| --- | --- |
| `web_list_apps` | 列出当前窗口中已安装的普通应用 |
| `web_open_app` | 通过宿主导航切到指定应用，等待它渲染 |
| `web_observe` | 读取当前插件可见文本、输入框、按钮和滚动区；可选附一张图 |
| `web_tap` | 点击观察中的元素，或按 Canvas 图像的 0–1 坐标点击 |
| `web_scroll` | 滚动插件内的容器，回传实际滚动量 |
| `web_fill` | 替换文字输入框内容，发送 input/change，支持中文 |

一次动作消费一次观察。换应用、重启实例、替换 iframe、窗口尺寸变化或页面变化后，重新观察再操作。
画布游戏可在换关、重绘关键状态时更新画布或其父元素的 `data-web-use-revision`，使旧观察立即过期。
私密区域标记 `data-web-use-private` 后会从普通 DOM 观察和重绘中排除；密码、文件选择等字段不会成为操作目标。
如果插件在同一 Canvas 混画公开内容与私密数据，应给整个画布加这个标记。

应用内 DOM 与受支持的同源 page iframe 都能直接操作，不要求每个插件另装扩展。
此版本使用 DOM 输入事件，复杂手势、富文本专用适配、跨域 iframe、整页真实屏幕流和操作系统控件不在本接口范围内。
画布图像来自可读 Canvas 的像素；普通应用图像来自 DOM 局部重绘，不能用于像素坐标点击。
读不到图像时，观察仍能返回文字与控件及截图错误。网页操作不会要求屏幕共享权限。

## 传输与任务边界

- `/api/web-use/ws`：浏览器启用模式后连接。必须登录且 Origin 与 Anka 一致。服务端分配临时窗口凭证。
- `POST /api/chat`：携带 `web_client_id` 时绑定该登录用户的连接，单窗口同一时刻只执行一个操作任务。
- `POST /api/web-use/image/{requestId}`：只允许该连接上传当前待处理观察的 JPEG/PNG，最多 1 MiB。
  图片仅进入下一轮模型输入，不写截图文件、会话历史或 SSE 工具卡。
- SSE 继续用于任务进度和终止。禁用模式、退出登录或页面隐藏会关闭连接；重连不会重放动作。
  动作超时或连接中断并不意味着点击没有发生，下一步应重新观察。

## 验证

在 `web/` 执行 `npm run typecheck`、`npm run build`，
再执行 `node scripts/check-web-use.mjs`（需要 Playwright、Chrome 与后端虚拟环境）。
如果 Playwright 装在项目外，用 `ANKA_PLAYWRIGHT_MODULE` 指向它的 `index.mjs`；
如果 Python 虚拟环境不在仓库根的 `.venv`，用 `ANKA_PYTHON` 指定解释器。
脚本启动本机临时端口、使用隔离账号和插件目录，在桌面和手机尺寸跑真实浏览器、FastAPI 和 WebSocket。
使用确定性的测试模型验证工具与图像传递，不消耗模型配额；真实模型找茬成功率和 iOS PWA 需另行验收。
